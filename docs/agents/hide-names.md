# Hide names

Notes for agents on the window's hide names mode, and on the four clones made for it: the mods in `packages/hide-names/mods/tabs-names/`, `packages/hide-names/mods/pane-names/`, `packages/hide-names/mods/hide-names/` and `packages/hide-names/mods/toast-names/`. The index and what holds for every mod are in `AGENTS.override.md`.

A mode of the whole window for a screenshot or a screen share, in which the names around the content are plausible made-up ones ("atlas", "Clients", "Refactor search index", `feat/search-filters`, "studio"). Shared `names.hidden` (`true`, else absent or `false`). `hide-names.toggle` turns it on and off (`cmd-shift-h` in `global`, and the palette's "Hide Names / Show Names"); the Usage dialog's toggle, its `h` key and `agent-usage.names` set the same flag. What it changes: the sidebar (`spaces-sidebar`), the agents list (`mark-agents-unread`), the tab bar (`tabs-names`), the pane headers (`pane-names`), the status bar (`hide-names`), its recent workspaces menu (`back-and-forward`), the Usage dialog (`agent-usage`) and the notifications (`toast-names`). What it leaves: the panes' content (terminals, the editor, the diff) and the right panel (`file-explorer`, `git-panel`, `project-search`), which are content the owner chose to show.

## What is where

- `alias.js`: the made-up names, a pure function of the kind (`project()`, `folder()`, `title()`, `label()`, `branch()`, `machine()`, `path()`) and the real string as drawn. The same file is in `hide-names`, `tabs-names`, `pane-names`, `toast-names`, `spaces-sidebar`, `mark-agents-unread`, `agent-usage` and `back-and-forward` (a mod imports only from its own folder): keep the copies the same. `alias.test.mjs` in `hide-names` tests it under `node --test`. The repository’s `docs/check-shared.py` checks all copies byte for byte.
- Started again, the app shows names: `hide-names` reads, in a task at its start, the app's process id and start time (`ps` on the `$PPID` of a program it runs, which is the app, called `Herdr`), keeps it in shared `names.boot`, and turns `names.hidden` off when the one kept is another run's. `names.boot` is written only when it changed.

## The four clones

- **Mod `tabs-names`** (`packages/hide-names/mods/tabs-names/`): a clone of Herdr's `tabs` (from version 0.1.18). The Power Tools panel switcher exposes Search when its layout child uses `project-search` and labels the `git-panel` child Git. The shipped Changes panel retains its own label. While names are hidden, a tab's label is `alias.label()` of what it would show (a tab's number and a bare program's name stay). The clone began with an empty `localStorage`: which side panel each space showed (`panels`) was Herdr's copy's, and is learned again.
- **Mod `pane-names`** (`packages/hide-names/mods/pane-names/`): a clone of Herdr's `pane` header (from version 0.1.18). While names are hidden, the folder is `alias.path()` (the space's real name, found through the pane's tab, picks the segment), and a terminal's name is its program's, or `alias.label()` of a name someone gave the pane, never the terminal's own title. A mod pane's name stays: it is the file shown. The Power Tools layout also passes `terminalHistory: true` to the header so plain mouse side buttons over a terminal run the [Back and Forward commands](back-forward.md). The header adds this handler only for a terminal, and only when opted in.
- **Mod `hide-names`** (`packages/hide-names/mods/hide-names/`): a clone of Herdr's `workspace-status` (from version 0.1.18). Changes: while names are hidden, `alias.machine()` for another machine and `alias.branch()` for the branch; the key command `toggle` (taken through `nextCommand()`, so by the copy on screen, which this one always is), in the palette through `mod.json`; and the start check above.
- **Mod `toast-names`** (`packages/hide-names/mods/toast-names/`): a clone of Herdr's `toast` (from version 0.1.18), which draws every notification, Herdr's own and every mod's `notify()`, since the layout's root has `"toast": "toast-names"`. Changes: while names are hidden, the title and body are drawn through `names.js`, and a machine's login toast draws `alias.machine()` in its title and command while Copy copies the real command; and a tooltip with the whole title and body when one of them is cut (more than one line, or more than 40 characters). `names.js` is pure and tested under `node --test` (`names.test.mjs`):
  - Herdr's agent toast (`alert` in Herdr's `src/window.rs`: the title `<name> needs you` or `<name> finished`, the body `<space> / <tab>`, the action `agent.focus`): the name is `alias.label()` unless it is a program's name the window knows (`terminals()`, `agents()`, `panes()`) or "An agent"; a body that is some space's name, ` / ` and one of its tabs' names becomes `alias.project()` of the space and the tab as `tabs-names` makes up a named tab (`alias.label()` with its lead program), a number staying.
  - Any other text, and an agent toast whose body names no tab now: every real name the window has (spaces, machines, branches, tabs, panes' and terminals' names, by that order when two kinds share a name) is replaced by its alias as a whole word (letters, digits and `_` join a word; case does not matter; the longest first), and this computer's home folder by `~`. Names of one letter, and names whose alias is themselves (`~`, a number, `main`, a program's), are left out. The sidebar's folders and a stack's name are not in that list: no toast of Herdr's names them, and `spaces-sidebar` gives its own stack toasts the made-up name when it posts them.
  - Herdr gives a card that grows with its text only to the mod named `toast` (`fitHeight`, in `open_overlay` in `src/window.rs`). Every other toast mod gets a fixed 340×72 card, in which the bundled code shows one line of the title and one of the body. The owner chose this over keeping Herdr's toast, for every notification and not only while names are hidden; the tooltip is what makes up for it. If Herdr lets a layout's toast mod fit its text, take that.
- In each of the four clones a changed region is marked with a comment that starts `names:`, so a port at the next Herdr update copies Herdr's new file and puts those regions back.

## Behavior to preserve

Spotify Mini reads the same flag. Its status item and tooltip say “Spotify” while names are hidden. The opened mini-player shows its music and playlist names.

- A made-up name is a function of the kind and the real string as drawn (trimmed, lower case), and nothing else: no map, no state, nothing written. That is what makes a project the same in the sidebar, the agents list, the pane header, the Usage dialog and a notification. Only `spaces-sidebar`' folder names depend on the other folders (`names.folderNames()`: in the order of their ids, each avoiding the names given before it), so two folders never read the same.
- Every mod only reads `names.hidden`, in `render()`. It is set only from a click, a key, a command or a task: setting shared state draws every mod.
- Only what is drawn changes. Ids, the model, the order, sorting, `setAgentOrder`, drag and drop and every comparison (`gitTail()`'s "the name already says it", the agents list's same-label check) use the real names.
- What is deliberately not hidden: the panes' content and the right panel; this computer ("This computer", "This Mac"); `~`, a tab's number, a program's name; `main`, `master`, `develop`, `dev`, `staging`, `production`, `trunk`, `HEAD`, a detached HEAD and a branch's conventional prefix (`feat/`, `fix/`, …); the text in the input of a rename dialog (a folder's, a space's, a tab's); the Copy of a machine's `hc machine login` (what is drawn is made up, what is copied is real).
- Not hidden either, being Herdr's: its menus and dialogs (Go to…, the palette, worktree, Settings, Machines), a peek's title, the welcome screen, and the window's title where the system shows it.
- Tried from a shell, in screenshots with names shown and hidden: the sidebar (folders, spaces with their repo and branch, a machine header), the agents list (priority view), the tab bar, a terminal pane's header, the status bar, and three toasts posted in the screenshot sandbox with the stage mod's overlay step (`openOverlay({ mod, kind: "toast", notification })` reaches the layout's toast mod whatever `mod` names): an agent's, an error naming a space and a path under home, and a machine's login. Their names matched the sidebar's and the tab bar's, and the real ones came back when shown. Not tried by hand when this was written: `cmd-shift-h` and the palette entry as keys, the Usage dialog with names hidden (its toggle, `h`), a sidebar menu and its tooltips, the rail, a pane someone named, an agent on another machine, sub-agent rows, a stack's button and notification, a toast's tooltip and its login Copy, an agent toast posted by Herdr itself (the sandbox posted one in its form), and the start check across a real restart of the app (its id was read and found the same across mod reloads).
